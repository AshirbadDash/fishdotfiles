# Fish Dotfiles

Personal Fish shell and terminal configuration.

## Quick install

```bash
git clone git@github.com:AshirbadDash/fishdotfiles.git ~/dotfiles
cd ~/dotfiles
./install.fish
```

## Included

- Fish configuration
- Fisher plugins
- Tide prompt
- Terminal packages
- Fish functions and completions

## Update

```fish
cd ~/dotfiles
git pull
./install.fish
```

## Security

Do not commit passwords, API keys, tokens, private SSH keys, or other secrets.
